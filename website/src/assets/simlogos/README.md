# Oyun (sim) ikonları

Üst çubuktaki simülasyon seçicide oyun adları yerine ikon gösterilir. Bu klasöre konan dosyalar derlemeye
kendiliğinden girer (Vite `import.meta.glob`). Dosya yoksa o oyun için kısa adı yazı olarak gösterilir.

Dosya adları (png ya da svg; svg varsa o kullanılır):

| Dosya | Oyun |
|---|---|
| `iracing.png` | iRacing |
| `acc.png` | Assetto Corsa Competizione |
| `ac.png` | Assetto Corsa |
| `lmu.png` | Le Mans Ultimate / rFactor 2 |
| `ams2.png` | Automobilista 2 / Project CARS 2 |

Öneri: saydam arka planlı, kare ya da karemsi, en az 64×64 px. Koyu zeminde okunacak renkte olmalı.
